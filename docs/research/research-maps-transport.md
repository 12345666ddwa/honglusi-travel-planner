## 1. 高德开放平台 Web服务 API 免费配额



**结论速览：新定价体系下配额按「月」计，个人认证开发者「基础LBS服务」共享 15万次/月（≈日均5000次），覆盖本项目所需的全部核心接口（地理编码/逆地理编码/驾车·骑行·步行·公交路径规划/距离测量/坐标转换/行政区划/IP定位/静态地图）。内测单人使用绰绰有余。**

### 1.3 接口归类确认（逐接口文档核对） `[✅实查]`



- **地理/逆地理编码**（v3/geocode、v3/geocode/regeo）→ 基础LBS服务，共享 15万/月 ✅

- **路径规划 2.0**（v5/direction/driving|walking|bicycling|transit，即新版「路径规划 2.0」文档）→ 基础 API，流量限制同基础服务配额；`strategy` 支持 32=高德推荐、34=高速优先、35=不走高速等 11 种策略 ✅

- **公交路径规划**（transit）→ 明确列在基础LBS服务「服务包含」清单中 ✅

- **高级路径规划**（含未来 7 天规划 v4/etd/driving）→ **仅向企业开发者开放，需商务咨询**，个人开发者不可用 ❌

- **公交信息查询**（公交站/线路 ID·关键字查询，v3/bus/*）→ 高级服务接口，「已通过个人和企业认证的用户提供每日一定量配额以供体验，更多需商务咨询」（**具体每日配额数字未公开，待注册后确认**）⚠️

## 2. 12306 火车票数据获取方案

**结论速览：可行。社区已验证「站点代码 → 车次时刻 → 余票/票价」完整链路，首选复用开源实现，无需自行逆向。**

- **已验证证据**（GitHub 调研报告 §8）：`alexlmoney83-oss/travel-planning-agent`（46⭐，MIT）以 MCP 协议接入 12306，实现「自动站点代码 + 时刻 + 票价」查询，作为其全国产数据源组合的核心，实际运行过。
- **技术形态**：12306 官方前端接口 `kyfw.12306.cn/otn/leftTicket/query`（余票+票价）公开可用，无需登录可查余票（下单才需登录）；需要设置 `RAIL_DEVICEID`、`RAIL_EXPIRATION` cookie（社区开源库均有实现）。
- **开源实现选型**：py12306 / 12306 各类查询库（内测版可复用 alexlmoney83 的 MCP 代码或直接 HTTP 调用）。
- **落地行动项（M1 实测）**：验证 2026-08 当前该端点的可用性与返回字段，确认票价字段完整性（二等座/一等座/硬卧等）。

## 3. 机票免费查询方案

**结论速览：内测版不接实时票务，采用「价格区间参考 + 标注估算」。**

- **业务规则**（借鉴 alexlmoney83 项目）：城市间直线距离 >800km 时，行程默认触发航班对比（高铁 4h+ 时飞机更划算）。
- **数据方案**：携程/去哪儿公开搜索页可尝试抓取（⚠️ 反爬程度中等，M1 实测）；抓取失败时用「同航线公开价格区间 + 淡旺季系数」给出 📊估算区间，并明确标注「估算」。
- **Amadeus Self-Service API**：对个人开放但需注册申请（免费层限测试），中国国内航线覆盖有限，不作为主方案。

## 4. 兜底方案：OSRM + 中国 OSM 数据质量

**结论速览：可用作高德失效时的兜底，不作主方案。**

- OSRM 公共演示端点 `router.project-osrm.org` 已在线验证可用（上一轮实测）✅
- 中国路网 OSM 数据覆盖：主干道/高速可用，但小路/乡村路、实时路况缺失，测算精度低于高德
- 定位：高德 API 异常时降级用 OSRM 保证「有路线可展示」，精度差异在方案页标注
