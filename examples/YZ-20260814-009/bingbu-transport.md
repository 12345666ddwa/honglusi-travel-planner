## §0. 12306 官方接口实查情况（如实报告）

按任务单要求，本部门尝试对 12306 余票查询接口 `https://kyfw.12306.cn/otn/leftTicket/query` 进行实查。

| 步骤 | 请求 | 结果 |
|---|---|---|
| 1. 获取首页 | `GET /otn/leftTicket/init` | HTTP 200，仅下发 `JSESSIONID` 与 `BIGipServerotn` cookie |
| 2. 设备指纹 | 首页/`HttpZF/logdevice` | **未返回 `RAIL_DEVICEID` / `RAIL_EXPIRATION`**。这两个 cookie 由前端 JS 依据浏览器指纹（RSA/算法计算 `expID`）生成后写入，纯 curl 无法获得 |
| 3. 余票查询 | `GET /otn/leftTicket/query?train_date=2026-09-22&from=CDW&to=GIW` | **HTTP 302** → `{"status":false,"c_url":"leftTicket/queryG"}` |
| 4. 备选接口 | `queryG`（仅靠 JSESSIONID） | HTTP 302，被拦回登录页 |
| 5. 车次信息 | `otn/queryTrainInfo/query` | `status:true` 但 `data:null` |

**结论**：12306 余票/票价查询接口要求 JS 生成的 `RAIL_DEVICEID` 设备指纹，纯 curl 无法绕过（302 拦到登录认证）。**本报告"成都→贵阳"票价改用可访问第三方数据源核验，并统一标注【📊估算/参考价】。** 下方具体车次时刻与票价为参考数据，出行前请以 12306 实时查询为准。
